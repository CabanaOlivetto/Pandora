# Pandora 🎮

Explore um labirinto mental em visão top-down, onde cada corredor reflete batalhas psicológicas reais. 
Caminhe por memórias, decifre enigmas e aprenda usando o autoconhecimento como arma

Controles padrões:
[W] Cima
[S] Baixo
[A] Esquerda
[D] Direita
[E] Interação

* [GameMaker](https://gamemaker.io/) - Engine de desenvolvimento.
* **GML (GameMaker Language)** - Linguagem de programação utilizada.

Funcionalidades Atuais
- [x] Movimentação básica do personagem.
- [x] Sistema de colisões.
